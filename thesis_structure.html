Introductionframing

Establishes the central problem: IMU-based gait authentication systems must continuously learn new users — but continuous learning creates dual risks: forgetting old users and leaking private information. Introduces the three-way tension between accuracy, plasticity, and privacy that drives the entire thesis. States research questions and contributions.

Closes with the CDMA spread-spectrum analogy that motivates CDML.

CDML: The Core Frameworkpaper replication + analysis

Fully replicates the reference paper's CDML mechanism (m = h ⊙ s_k): task-specific pseudo-random binary sequences modulate the embedding, simultaneously preventing catastrophic forgetting and scrambling the feature space against privacy attacks. Compares CDML to FiLM/Adapt. Introduces the first privacy evaluation: MIA via CE-loss scoring in "no-seed" vs "oracle" attacker modes. Reproduces Table III (privacy-accuracy trade-off) and visualizes the modulation sequences.

Novel Learning Methodsoriginal contributions

Presents the original learning-side contributions. KD-CL adapts the RCAT distillation loss (negative-flip penalty) to anchor embeddings to past tasks without storing raw biometric data. Combining KD-CL with CDML yields the strongest accuracy-privacy joint improvement. Wavelet Generative Replay (WGR-CDML) synthesizes privacy-compliant proxy samples via DWT decomposition of gait signals. CaSpeR and LiDER are evaluated as geometric regularizers. All methods are compared on the unified accuracy-forgetting-privacy triangle.

7
Defense Mechanismsoriginal contributions

Complements CDML's embedding-level protection with output-level and training-level defenses. Inference-time output perturbation (Gaussian logit noise, temperature scaling) blunts attacks that exploit confidence values. DP-SGD provides a formal privacy guarantee at training time. Machine unlearning (Gradient Ascent + FUMA verification) implements the "right to be forgotten" without full retraining. The chapter synthesizes a layered defense architecture and quantifies each layer's contribution.

Output perturbation Temperature scaling DP-SGD Machine unlearning (GA) FUMA verification Layered defense stack
8
Architectural Extensionsarchitecture exploration

Asks whether the conclusions change if the backbone or the adaptation strategy changes. The Transformer encoder ([CLS]-token, sinusoidal positional encoding) is compared against GaitCNN: attention patterns reveal which gait-cycle phases the model focuses on. LoRA (Low-Rank Adaptation) is introduced as a parameter-efficient CL alternative, evaluated both alone and combined with CDML. The key insight: LoRA alone provides negligible privacy; CDML is the essential privacy layer. Oracle vs no-adapter attack modes make this crisp.

Cross-Dataset Generalizationgeneralization

Tests whether the framework transfers beyond the main dataset. Establishes upper-bound baselines on three datasets (main IMU, UCI HAR, WISDM walking) with a single non-CL model. Then evaluates cross-dataset LoRA transfer: a backbone pre-trained on 118 subjects is frozen; only LoRA + CDML adapters are trained on UCI HAR and WISDM. This validates the architectural design for realistic deployment where a foundation model is adapted to new populations.

Ablation Studies and Interpretabilityunderstanding

Opens the black box. t-SNE visualizations of the embedding space under four conditions (standard, CDML backbone, CDML modulated oracle, CDML modulated zeroed) reveal whether CDML changes what the backbone learns or only scrambles the output. Linear probes quantify how much identity and task information is linearly decodable from each embedding. Sensitivity analyses cover distillation λ, LoRA rank, task ordering, and sequence length — showing which design choices matter.

11
Conclusionswrap-up

Synthesizes findings across the accuracy–forgetting–privacy triangle. Recaps which combinations of methods achieve the best joint performance. Discusses limitations: computational overhead, key management, reliance on discrete task boundaries. Outlines future directions: online/streaming CL, federated extensions, hardware-constrained deployment, and formal privacy guarantees via composition of DP and CDML.
